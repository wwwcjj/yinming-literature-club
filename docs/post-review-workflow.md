# 文学分享编辑流程

## 发布流程

1. 同学在 `share.html` 的腾讯文档收集表中填写标题、署名、类型和正文。
2. 投稿邮件发送给社团编辑。
3. 编辑将正文交给 AI 做初步检查。
4. 编辑结合原文和实际语境作最终判断。
5. 通过后，将内容整理成一张 `post-card` 加入 `share.html`，再推送网站。

## 腾讯文档表单接入

将腾讯文档收集表的公开填写链接填入 `js/submission-config.js`：

```js
window.SUBMISSION_FORM_URL = '你的腾讯文档收集表链接';
```

网站会优先尝试在投稿卡片中嵌入表单；如果腾讯文档禁止 iframe，页面会提供“在新页面打开投稿表单”的备用链接。

## AI 初审提示词

```text
你是文学社投稿的内容初审助手。请只做风险识别和编辑建议，不要替编辑做最终发布决定。

请检查下面的投稿是否存在：
1. 明确的违法违规内容或现实伤害指引；
2. 煽动暴力、仇恨或针对具体群体的攻击；
3. 明显的政治极端宣传或试图组织现实伤害；
4. 人身攻击、骚扰、色情低俗、广告灌水；
5. 未经处理的个人隐私、联系方式或他人身份信息；
6. 大段疑似转载或抄袭内容。

请输出：
- 结论：建议通过 / 建议人工复核 / 建议退回修改；
- 触发的风险类别；
- 对应原文片段；
- 不改变作者原意的修改建议。

不要因为作品表达了悲伤、批判、讽刺、社会观察或不同意见就直接判定违规；需要结合具体文本和语境判断。
```

AI 结果只作为编辑参考。最终是否发布由社团编辑决定，疑似内容统一进入人工复核。
